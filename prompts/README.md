# AI Prompt Log

AI assistance was used during development of this Laravel Store Order & Inventory Mini-System.

The prompts were used for guidance, implementation review, testing, debugging, and documentation.

## Prompt 1 — Project Structure

Requested guidance for implementing the Laravel Store Order & Inventory mini-system, including products, customers, orders, order items, migrations, relationships, factories, and seeders.

## Prompt 2 — Order Creation

Requested help designing a clean Laravel order creation flow using FormRequest validation, Eloquent models, a service layer, database transactions, stock validation, tax calculation, and stock deduction.

## Prompt 3 — Concurrency

Requested an explanation and implementation approach for safely handling concurrent orders using database transactions and `lockForUpdate()` so that stock cannot be oversold.

## Prompt 4 — Queue

Requested guidance for dispatching a queued order confirmation job after successful order creation and simulating an email using Laravel logging.

## Prompt 5 — Testing

Requested help creating PHPUnit feature tests covering successful order creation, insufficient stock, customer order history, low-stock products, and duplicate product quantities.

## Prompt 6 — Debugging

Used AI assistance to diagnose and fix implementation issues encountered during development, including Laravel migration ordering, API route namespaces, validation responses, and test assertion type mismatches.

## Prompt 7 — Documentation

Requested assistance preparing the README with setup instructions, API documentation, architecture, concurrency handling, queue configuration, assumptions, design decisions, and testing instructions.
